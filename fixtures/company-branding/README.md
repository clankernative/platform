# Independent Company Branding

This sample brand manifest and licensed logo exercise company-owned branding
independently of app artifacts and platform chrome. The asset and HTTP tests build
these inputs into pinned bundles and bind them to isolated test instances.

They do not define the appearance of every app or customer. A real company owns
its branding input in its instance repository. Asset normalization, integrity,
scope, and rendering contracts are tested in the Rust asset and HTTP suites.
