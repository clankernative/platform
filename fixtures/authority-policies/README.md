# Authority Policy Test Inputs

These JSON files supply explicit operation, row, field, edit-version, and job
grants for conformance tests and local demos. Filenames identify the sample
contracts they authorize, not additional application source repositories.

Tests load these policies into temporary instance configurations; local demo
commands use the corresponding reviewed policy when installing a sample. They
are not automatically granted to company applications or production defaults.
Real company policy belongs to its instance repository.
