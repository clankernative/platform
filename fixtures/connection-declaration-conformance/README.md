# Connection declaration conformance

`App.definition.connections` registers each app-owned requirement once. The
native build derives the artifact's `connection_declarations` from that checked
registration and admission compares it with the compiled worker.

The fixture covers both a mapped company account and explicit external-account
approval, with distinct stable logical IDs and closed Calendar semantic access.
It does not connect to Google, qualify a registration, or expose generated `Use`
or event execution APIs. Those runtime and generation slices remain separate.
