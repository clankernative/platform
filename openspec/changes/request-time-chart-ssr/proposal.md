## Why

Native already renders current authorized Roc query results on requests and live refreshes, but has no approved runtime presentation transformation port. Pre-generated SVG fixtures do not satisfy dynamic charts or server-backed range selection.

## What Changes

- Add an optional provider-neutral presentation ABI 1: typed input/output schemas, separately approved executable identity, isolated bounded exchanges, and request-local memoization.
- Admit an ordinary `ui_scene` template helper against locked app-owned presentation contracts; never add ECharts vocabulary, raw-markup insertion, or arbitrary JavaScript to the host.
- Render checked SVG geometry through ordinary templates and existing page/live transport.
- Exercise changing persisted Roc data and checked range routes in the isolated chart consumer; preserve an accessible no-JS path and app ownership of state.
- Add deterministic protocol, model, scheduler/failure and real-worker conformance gates. Qualification remains separate from full Platform verification.

## Capabilities

### New Capabilities
- `runtime-presentation`: approved bounded pure presentation transformations for dynamic typed view data.

### Modified Capabilities
None. Build-time UI assembly, worker confinement, business commands, and binding ABI 2 remain unchanged.

## Impact

Platform template catalog/admission/runtime, generic worker supervision reuse, and the isolated chart consumer. The independently scoped clanker-ui change supplies the engine, schemas and SVG adapter. No Node server, build-time download, app-authored generator, toolchain pin relaxation, component release or deployment.
