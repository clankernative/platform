# Gitea Actions wire fixtures

Captured with read-only authenticated requests to a Gitea 1.27.0 server on
2026-09-25: organization Actions runs (limit 2), jobs (limit 2), and runners.
The server's own Swagger schema was also inspected. The fixtures establish
pagination envelopes, status/timestamp shapes, legacy empty timing, omitted
runner names, and runner label objects. They are not generated by our adapter
or simulation.

Private actor/repository/PR objects were removed from the runs fixture. Server,
organization, repository, branch, SHA, display names, job/step/runner names and
label text were replaced with examples. Numeric IDs, attempts, pagination counts,
status/conclusion and timestamp values retain the recorded wire form. These
redactions do not establish claims about fields the adapter does not consume.

API reference: https://docs.gitea.com/api/1.27/
